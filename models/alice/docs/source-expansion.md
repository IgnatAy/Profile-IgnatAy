## 复现

在已有四套模型素材的工程根目录执行：

```sh
ALICE_SOURCE_DIR='/Users/1gnat4y/Desktop/立绘/2' node models/alice/scripts/prepare-alice-expanded.cjs
node models/alice/scripts/check-alice-all-poses.cjs --out work/alice/source-expansion
node models/alice/scripts/check-alice-faces.cjs
node models/alice/scripts/check-alice-expanded.cjs
pnpm exec tsc --noEmit
pnpm build:pages
node scripts/check-performance.mjs
```

新增脚本复用已有正面、前倾的拆层轮廓，按侧脸原画单独定义头部/发束轮廓。源像素逐一归属身体、头部、发束或蝴蝶结；隐藏接缝余量只从相邻原画像素延展。眼和嘴的差分在原坐标上提取并保留原画边界。三个侧身姿态的蝴蝶结在原图中不可见，对应占位纹理透明，避免画出不存在的部件。

运行素材在 `public/models/alice/`，新增 65 张纹理，共 118 张；新增部件提供 PNG 制作源和 WebP 运行版。构建继续排除制作用 PNG，并保留运行 WebP。素材与备用整图地址均带版本号，防止浏览器沿用旧缓存。

检查图与报告保存在 `work/alice/source-expansion/`，其中 `model-overview.png` 是九姿态实际 Canvas 合成总览。这里的渲染检查使用生产代码的 Canvas 后备路径，不等同于浏览器 WebGL 或真机测试。
