# 黑色长裙模型

来源：桌面 `立绘/3`，39 张 PNG 均已作为完整随机表情接入，包括细微视线、惊讶、微笑、脸红。详见 [完整表情差分](expressions.md)。以下表格说明基础绑定的眨眼/口型来源。原文件不改动。运行资源位于 `public/models/alice-dress/`，套装 ID 为 `dress`。

每次打开或刷新网页时，从 `alice-models.ts` 注册的全部套装中等概率选择一次；允许连续选中同一套。选择仅保存在当前文档内存中，聊天、语言切换、板块切换、重新渲染或角色组件重新挂载均沿用当前套装。自动待机只选择当前套装支持的姿态。

## 拆层与动作

八姿态各有 13 张基础运行纹理：身体、头部、两侧发束、兼容透明蝴蝶结、接缝背衬、三张眼帧、两张嘴帧及两张头部表情底图。共 104 张 WebP，另保留 PNG 制作源。身体运行纹理高度最多 3600，其他纹理使用无损 WebP。全部图层尺寸与原图坐标记录在各姿态的 `manifest.json`。

头部原尺寸合成使用双线性采样，避免宽滤波核在拆层边界产生细缝；完整头部仍由渲染器高质量缩放。

共用现有 Canvas/WebGL 渲染器、发束惯性、呼吸、身体网格、自主动作、减少动态效果和后台暂停。托腮、掩嘴的局部转头和点头幅度为零，使脸与手保持相同的上半身变换；只让另一侧垂手产生局部摆动。端茶扩大上身刚性区域，双手与杯碟同步。前倾的双手在身后，不配置可见手臂摆动。

模型按需加载，缓存仍最多保留两种「套装 + 姿态」，分层失败时使用对应姿态的整图回退。构建只发布运行 WebP，保留本地 PNG。仍属于现有的原画拆层模型，不是 Cubism `.moc3`。

## 复现与验证

在项目根目录使用 Node 24 与已安装的依赖：

```sh
ALICE_SOURCE_DIR='/Users/1gnat4y/Desktop/立绘/3' node models/alice/scripts/prepare-alice-dress.cjs
node models/alice/scripts/check-alice-dress-recomposition.cjs
node models/alice/scripts/check-alice-all-poses.cjs --model dress --out work/alice/dress
node models/alice/scripts/check-alice-expanded.cjs --model dress
node scripts/check-alice-models.mjs
pnpm exec tsc --noEmit
pnpm build:pages
node scripts/check-performance.mjs
pnpm build
```

素材制作及重组脚本使用本机已有的 sharp；离线渲染检查使用已有的 @napi-rs/canvas，网站无需新增依赖。

八张 PNG 中性重组均无遗漏或新增像素，透明度一致，不透明 RGB 无差异。通过三套共 415 项绑定及渲染检查（冬装 157、披肩装 122、长裙 136），包括变形连续性、面部比例、双脚固定、快速转向及表情边界。随机选择覆盖三等分区间边界、服务端默认、客户端独立选择、当前文档稳定与刷新重新选择。加载检查覆盖三套全部 24 种姿态与缓存隔离；构建输出检查覆盖共 326 张运行纹理的根路径/仓库子路径。

表情、姿态总览、最大偏转及拆层图位于 `work/alice/dress/`，仅作本地检查，不随网页发布。离线渲染检查使用 Canvas 路径，不等同于浏览器 WebGL 或真机性能测试。本次未推送或发布。
