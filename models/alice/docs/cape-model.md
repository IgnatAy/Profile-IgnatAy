# 披肩装模型 · 2026-09-08

素材来自桌面 `立绘/4`，原始 PNG 保持不变。新增 `cape` 套装，运行素材存放在 `public/models/alice-cape/`；原冬装 `winter` 继续使用 `public/models/alice/`。这是现有 Canvas/WebGL 2D 分层体系中的第二套模型。

## 页面行为

每个新页面文档在客户端等概率选择一套模型。选中结果仅保存在模块内存中，不写入 localStorage 或 sessionStorage；打开、刷新重新随机，允许连续选中同一套。聊天、语言切换、组件重新挂载及待机姿态变化保持当前套装。延迟加载组件仍在页面主内容加载后启动，不影响服务端渲染。

`alice-models.ts` 分别注册套装路径、素材版本及支持的姿态。新模型只使用自己的七种姿态，不随机请求缺少原画的托腮或正面交手。加载缓存的键包括套装和姿态，仍最多缓存两种姿态。两套共用身体网格、发束惯性、头肩动作、原生表情合成、减少动态效果、后台暂停和整图回退。

## 拆层与限制

每个姿态包含 13 张基础运行纹理，另有两张独立绒球纹理；前倾抱臂只有一只绒球露出，共 104 张运行纹理。同时保留 PNG 制作源和 WebP 运行版。眼睛与嘴型从对应原画坐标提取，边缘在局部区域内平滑融合。眼部与嘴部区域固定在头部上，避免睫毛被归入发束后留下双影。身体纹理最长高度为 3600，面部、发束与绒球采用无损 WebP。

披肩装没有原冬装的蝴蝶结，对应兼容图层透明。头部和披肩使用各姿态独立的绑定坐标，接缝余量来自相邻原画像素，不添加新画面。前倾抱臂使用相同角度的闭眼差分，以 x = -88px、y = 0 对齐。常态及侧身垂手缺少本姿态张嘴素材，因此不会强行驱动口型；其他五种姿态支持原画嘴型。

胸前绒球及细绳从各姿态原画单独提取，身体层的原绒球与投影使用相邻衣料补齐，柔和投影随绒球移动。两只绒球分别绕领口绳根悬挂，跟随上半身并带有独立的惯性、周期和阻尼；沿用现有动画循环，减少动态效果时停止局部摆动。前倾抱臂保留手臂遮挡，只让露出的绒球小幅运动，袖口附近的投影平滑衔接。绒球被另一只绒球或袖口遮住的少量边缘，使用自身可见侧像素补齐。制作与检查入口分别为 `prepare-alice-pendants.cjs` 和 `check-alice-pendants.cjs`。

绒球抠图修订 `cape-pendants-20260908-3`：椭圆仅用于寻找球缘，实际遮罩沿原画的深色轮廓提取；重叠处使用各姿态单独标定的分界，后球连同透明度一起从自身可见侧补齐。细绳与偏移的柔和投影连续提取，投影始终归属对应绳子。身体底图按独立的连续区域补色，缩小球周阴影范围，保留前倾姿态的衣物竖缝和抱臂袖口。每次制作先从原画恢复胸前区域，避免反复制作积累残影；原始 PNG 不变。

新增 `node models/alice/scripts/check-alice-pendant-mattes.cjs`：检查 254 个衣料与绳影像素，包括原来被当成不透明球体带走的衣料、细绳中段与末端投影、固定衣缝，以及七姿态重复提取的逐字节一致性。与绒球动态检查、原画静态重组检查配合使用；对照图仍输出到 `work/alice/cape-pompoms/pendants-motion-review.png`。

姿态静止表情、半闭/闭眼和说话均使用现有生产渲染代码检查。离线图片验证的是 Canvas 后备路径，不等同于浏览器 WebGL 或真机测试。

## 复现与检查

在项目根目录，使用本机 Node 运行：

```sh
ALICE_SOURCE_DIR='/Users/1gnat4y/Desktop/立绘/4' node models/alice/scripts/prepare-alice-cape.cjs
node scripts/check-alice-models.mjs
node models/alice/scripts/check-alice-all-poses.cjs --model cape --out work/alice/cape
node models/alice/scripts/check-alice-expanded.cjs --model cape
node models/alice/scripts/check-alice-cape-recomposition.cjs
node models/alice/scripts/check-alice-pendants.cjs
pnpm exec tsc --noEmit
pnpm build:pages
node scripts/check-performance.mjs
```

生成脚本使用本机已有的 sharp，模型检查使用已有的 @napi-rs/canvas；运行网站无需新增依赖。总览与表情检查图位于 `work/alice/cape/`，绒球摆动检查图位于 `work/alice/cape-pompoms/`，不会随网站发布。

最终 PNG 中性重组与七张原画逐像素比较，要求无像素遗漏或新增、透明度一致，最多允许 1 级 RGB 合成舍入差异；不透明像素的舍入差异仅允许出现在绒球纹理范围内。回归覆盖原冬装 157 项、披肩装 122 项绑定与渲染检查，13 个绒球图层的悬挂点、独立阻尼、连续快速转向和减少动态效果，以及随机选择、页面生命周期、两套模型缓存隔离、两姿态缓存上限、失败重试、全部表情合成、222 张运行纹理的根路径及仓库子路径解析。另执行类型、修改代码 lint、静态构建和 Vinext 构建检查。本次更新本地工程，未推送或发布。
