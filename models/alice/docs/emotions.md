# 有珠情绪与阅读停留

累计惹恼锁定：每次成功完成的回复若为 annoyed 或 angry 且强度至少 0.5，计为一次；同一文档累计 3 次后，无论当前套装是哪一套，都固定为黑衣带帽披肩装 cape / relaxed / 13_11_00 红眼形态。此状态优先级为 100，覆盖企鹅出场保护，暂停所有随机姿态和表情切换，禁用输入框、发送、Enter 和重试；历史仍可查看。切页、切语言、开关聊天、错误回退和组件清理均不会解除，刷新或关闭网页后重置。仅统计最终成功回复，失败、取消、接口回退前的临时情绪不计数；计数不受最近 10 轮历史截断影响。

自然随机模式：annoyed / angry 相关表情的权重为普通表情的 4%，最低强度达到 0.8 的极端愤怒表情不进入随机池；只有不耐烦表情的姿态也同步降低权重。有其他平静表情时避免连续重复；若只有一张平静表情，允许保持，避免为了换表情而必选生气。语义情绪匹配仍可使用完整原生表情集。

企鹅出场保护从选中套装开始，覆盖素材加载、淡入、1.5 秒气泡延迟及 4.5 秒展示；气泡自动结束或手动关闭才解除。保护期间切换板块、标志返回主页、前进/后退均保持企鹅，不补抽或排队；解除后下一次实际切页恢复换装。后台暂停计时，切语言、减少动态效果和本地预览中的切页不重启气泡。累计惹恼的最终锁定优先。

2026-09-08。九种语义情绪：neutral、attentive、thinking、pleased、proud、shy、surprised、annoyed、angry。六套模型的 42 个姿态组、144 个原生状态均在 `../alice-affect-map.json` 人工视觉标注了权重、强度区间和画面线索。标注是对角色原画的主观解读，可以继续调整，不由文件编号推断。该文件独立于素材生成清单，重建纹理不会覆盖标注。

`../alice-affect-selection.ts` 在当前套装里按权重、强度与上次选择排序，从最高分附近的最多三个候选中加权抽取。同一表情可适配多个情绪，姿态与面部作为完整组合。无适配素材时使用明确的语义回退：angry → annoyed → neutral；proud → pleased → neutral；thinking → attentive → neutral 等。冬装、毛边斗篷没有强烈愤怒素材；企鹅仅一个 neutral/attentive 状态。披肩红眼 `13_11_00` 和毛衣阴影脸 `01_10_03` 分别要求至少 0.85、0.8 强度。

所有六个页面板块在前台且窗口有焦点时累计停留 45 秒，触发 0.65 强度的自豪，保持 6 秒。打开聊天、回复中或聊天情绪尚在保持时暂停计时；切换板块重新计时，取消旧板块的阅读反应。每个板块在同一文档中最多成功触发一次，刷新重置。快速切页与摄影点击不触发情绪。阅读计时不要求鼠标持续移动，不向接口发送行为记录；它是本地反应规则，不保证访客确实在阅读。

`lib/alice-affect.ts` 的优先级为聊天 80、打开聊天的关注 50、阅读 40、回归平静 0。聊天情绪保持到流结束，再持续 4.5 秒；其他反应按各自时长结束。随后平静 1.2 秒，再恢复随机待机。低优先级请求直接丢弃，不在之后重放旧反应。保持时间仅计算网页可见时间。组件卸载清理定时器、订阅和请求。

受控情绪期间，随机姿态与随机表情时钟暂停；身体、头发和呼吸继续现有运动。有配套嘴型的脸可以继续说话，完整原生差分保留自己的眼、眉、嘴、脸颊，不切回默认脸、不叠加不兼容的嘴型。减少动态效果时允许显示一次静态情绪变化，原有动画限制保持有效。

模型每次回答第一行输出 `[[AFFECT:proud:0.65]]`，下一行开始正文。`lib/alice-reply-parser.ts` 接收已移除思考内容的累计文本，只解析开头一次；不解析用户消息或正文中的同类文字。控制头可按任意字符拆包，最多允许 128 字符，情绪白名单与强度范围由前端验证。缺失/非法头使用 neutral；不完整的保留控制头不展示，只有头没有正文视为空回复。正常正文不等待头。

有效情绪先发出，正文延后约 180 毫秒开始显示。该提前量不承诺冷加载纹理已完成；解码期间继续显示上一画面，不无限阻塞文字。Gemini 和备用接口的 SSE/JSON 路径共用解析层，最终返回与可见历史只保存清理后的正文。主接口失败会取消其延迟正文，重置情绪到思考，再启动备用解析；取消请求不进入备用接口。拆包的 Gemma 思考/轮次控制字符也先缓冲。

验证：`node scripts/check-alice-affect.mjs` 检查全部素材覆盖、九种情绪回退、前缀拆包、前台/焦点/聊天暂停、优先级、到期与清理；`node scripts/check-alice-client.mjs` 检查两接口两格式、延迟正文、思考字符拆包、失败与中途取消；`node scripts/check-alice-expression-clock.mjs` 检查受控差分长期保持与待机恢复。检查使用模拟接口和可控时钟，不等同于真实模型遵循率或浏览器视觉实测。
